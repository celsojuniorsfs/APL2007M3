# APL2007M3 Console Application

## Overview
APL2007M3 is a console application developed in C# that demonstrates basic functionality and serves as a template for further development. This application is designed to be simple and easy to understand, making it suitable for learning and experimentation.

## Features
- Basic console input and output
- Demonstrates the use of C# 12 features
- Built on .NET 8.0

## Getting Started

### Prerequisites
- .NET 8.0 SDK installed on your machine.
- A code editor or IDE of your choice (e.g., Visual Studio, VS Code).

### Building the Application
To build the application, navigate to the project directory and run the following command:

```
dotnet build
```

### Running the Application
After building the application, you can run it using the following command:

```
dotnet run
```
